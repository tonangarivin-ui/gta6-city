Solara: Last Light — an original sun-soaked coastal open-world crime sandbox, written from scratch for the browser. A pseudo-3D canvas city of five districts, drivable traffic, pedestrians, a wanted level with police pursuit, a five-mission story chain and three side activities.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or just open `game/index.html` in desktop Chrome. No build step, no network requests.
